Answer each question in your own words before making the repository public.

- [ ] How do *An. gambiae*, *An. coluzzii* and *An. arabiensis* differ, and why analyse them separately?

## The data

## The analysis

- [ ] If V402L + L995F = 100 % in a cohort, what does that imply about the susceptible allele? What else could produce it?
- [ ] How did the known L995S and N1570Y patterns serve as an answer key?
